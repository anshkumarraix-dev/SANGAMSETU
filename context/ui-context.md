# SangamSetu (संगमसेतु) — UI Design & Brand Context

## 1. Official Government Aesthetic Standards
- **Primary Government Palette**:
  - National Navy / Deep Blue: `#0a192f`, `#0f2744`, `#1e293b`
  - National Saffron / Amber: `#f59e0b`, `#d97706`, `#b45309`
  - National Emerald / Green: `#059669`, `#047857`, `#065f46`
  - Neutral Backgrounds: Crisp `#f8fafc` (slate-50) and pure white `#ffffff` with high-contrast text `#0f172a`.
- **GIGW 3.0 Compliance**:
  - Skip to Main Content anchor on every page.
  - Interactive font-size switcher (`A-`, `A`, `A+`) modifying document root scale.
  - High-contrast toggle for visual accessibility.
  - Bilingual interface support (English / हिन्दी).
  - Explicit `id` attributes on key interactive containers.
  - Zero gradient text, zero informal emojis in public UI.

## 2. Terminology & Brand Integrity
- **Permitted AI Terminology**: "SangamSetu AI Engine", "AI-Powered Scoring Matrix", "SangamSetu Evaluation Algorithm", "GFR 149 Automated Evaluator".
- **Prohibited Vendor Names in Public Copy**: "Gemini", "OpenAI", "ChatGPT", "Claude", etc.
- **Simulation/Sandbox Handling**: Public pages are strictly official statutory views. Internal verification test runners are accessible exclusively within the authenticated Admin Mission Control (`/dashboard`).
